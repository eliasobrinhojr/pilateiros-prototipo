Este é um protótipo: parece o app, mas nada é salvo. Os dados são de uma aluna inventada, a Lu, da Turma das 7h, com a instrutora Carla.

Não tem cadastro: na entrada, escolha ver como aluna ou como instrutora.

Toque nos botões como se fosse o app de verdade. Alguns são só demonstração e avisam isso. Para voltar, use a seta no topo da tela ou o voltar do celular.

Algumas telas têm uma pergunta para você. Responda pelo WhatsApp, do seu jeito; pode ser por áudio.

No nome de cada tela, v1 é o que entra no lançamento; v2 e v3 vêm depois.
